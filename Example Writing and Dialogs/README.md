# Example Writing and Dialogs

Style and dialogue reference only. **Nothing in this folder is canon.**

Drop prose samples here that demonstrate the voice, rhythm, dialogue behavior, and level of sensory detail this series should reach — early drafts, pastiche, an author's own prior work, or a scene written purely to find the tone. The chapter writer reads this folder before drafting to calibrate *how* it writes.

Rules:

- Setting, character names, and events in these samples never enter canon. Only rhythm and behavior carry over.
- If a sample contradicts `WorldState/BookCodex.json`, the codex wins without discussion.
- When a sample stops representing the target voice, delete it. A stale reference is worse than none.
